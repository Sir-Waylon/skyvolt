## Architecture (short)
- engine3/*.js are concatenated into one global script (later declarations override earlier; order in build_open.py/build3.py). 
- events/<slug>/pack.json holds questions. Circuit pack is the MASTER (never regenerate; rebuild applies src/audit_circ/*.json via src/applyextra.py before shortify). Meteorology pack is regenerated by src_met/mkmet.py each rebuild, then src/audit_met/*.json applied.
- Apex/Quanta questions are generated by src_adv/*.py (t_apex.py etc.).
- Question schema: id,t(topic),l(1-3),b,type(mcq|multi|short|order|match),q,o(correct first),w(why),sol[] (steps),fp(family),num{v,tol,u,free,show}. Units: only electrical units (V A Ω W J C F H Hz s Wh N/C V/m %) with SI prefixes are parsed; `h`/`min` values are stored in seconds by applyextra; other units are marked `free` (unit ignored) with `show` text.
- Practice screen (engine3/session.js): #sess is a flex column; .s-top, .s-body (scrolls), then optional .tbar (tools) and .sheet (footer) pinned at the bottom. Menu (⋯) holds example + "How sure?". Skip/wrong answers are re-queued via requeue()/skipNow() (Z.rq3). lock.js = lock-in retrieval checks, confidence calibration. Break timer uses actNow() (active-tab time).
- Labs: engine3/sandbox.js + labs2/3/4.js (`window.__labApi`).
